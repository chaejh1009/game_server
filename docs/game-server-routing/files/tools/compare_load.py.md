# `tools/compare_load.py`

## 책임과 경계

저장된 두 WS 부하 결과를 나란히 읽고 요청 간격·요청 시간의 일치 여부를 출력한다.

## 진입점과 실행 흐름

1. left/right 위치 인자로 두 JSON 파일을 읽는다.
2. 각 profile과 실제 경과 시간·peak 연결·성공/오류·처리율·p95를 출력한다.
3. interval_seconds와 profile.seconds만 같음을 비교해 bool로 출력한다.

## 함수·클래스

직접 선언한 함수·클래스는 없다. 위의 최상위 실행문이 파일의 실행 경로다.

## 현재 구현에서 확인할 점

차이가 있어도 자동 실패하지 않는다. 처리율 개선을 판정하거나 동일 하드웨어·계정·서버 상태를 보장하지 않는다.
